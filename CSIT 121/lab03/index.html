Blog Post 2: Styling My Page with CSS

Adding Style to My Webpage

For this assignment, I practiced adding an external stylesheet to my HTML page. I placed my styling rules in a separate file named styles.css and connected it to index.html using a link element in the head. Keeping the styles separate helped me organize the page and focus on its appearance.

What I Learned

I learned how to use CSS selectors to style elements such as headings, paragraphs, and links. I practiced changing the background color, text color, font family, and font size. I also used margins to create space outside elements and padding to create space inside them. Adding borders and spacing made each blog post easier to distinguish.

Another lesson was the importance of consistent structure. I followed the same pattern for both posts: an introduction, a section about what I learned, and a list of helpful links. I also turned the original web addresses into clickable links. Hand coding the page gave me more practice with opening and closing tags, nesting elements, and organizing my code.
